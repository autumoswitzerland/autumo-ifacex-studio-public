# ifaceX Studio FX

ifaceX Studio FX is used to develop, create, and test interface processor
configurations (IPCs) for the [autumo ifaceX](https://ifacex.autumo.ch)
data integration and exchange platform.

All releases of ifaceX Studio FX are published in the new repository:

**https://github.com/autumoswitzerland/autumo-ifacex-studio-fx-public**

You find the ifaceX Studio FX installers for Windows, macOS, and Linux here:

https://github.com/autumoswitzerland/autumo-ifacex-studio-fx-public/releases

* **Linux**: `ifaceX-Studio-FX-X.Y.Z-amd64.deb`
* **macOS (Apple Silicon)**: `ifaceX-Studio-FX-X.Y.Z-arm64.pkg`
* **macOS (Intel)**: `ifaceX-Studio-FX-X.Y.Z-x64.pkg`
* **Windows**: `ifaceX-Studio-FX-X.Y.Z.exe` and `ifaceX-Studio-FX-X.Y.Z.msi`

For further information, download the [ifaceX Studio Manual](https://products.autumo.ch/ifacex/download).

## Features

- **Integration Development**: ifaceX Studio FX provides tools for developing and testing IPCs for integrations between various clouds, systems and applications, enabling data exchange and process automation.
- **Graphical User Interface**: A user-friendly GUI allows users to design IPCs visually, reducing the need for coding.
- **Built-in readers and writers**: The Studio provides forms for many readers and writers (CSV, JSON, databases, MongoDB, REST, files, cloud storage, mail and more) that can be combined freely into an IPC.
- **Debugging and Testing**: Users can debug and test their integrations within the studio, ensuring reliability before deployment.
- **Data Transformation**: The tool supports data transformation capabilities, allowing users to transform, manipulate and convert data as it moves between systems.
- **Documentation and Support**: Comprehensive documentation is provided, along with support resources.
